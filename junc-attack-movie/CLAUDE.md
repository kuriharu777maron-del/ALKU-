# JUNC アタックムービー制作プロジェクト

このディレクトリは「JUNC（愛媛の経営者団体）」向けアタックムービー制作を、AI生成ツールを使って
高速に進めるための作業基盤です。詳細な経緯は `docs/meeting-notes-2026-08-16.md` を参照。

## プロジェクトの方向性（絶対にブレさせないこと）

- **トーン**: 既存の経済団体的な「丸くて平均的」な雰囲気は避ける。異端児・破壊者的（レッドブル、
  ハーレーダビッドソン、ブルードッグ的な）尖ったブランディングを目指す。
- **ターゲット**: 愛媛の経営者。旅館・みかん農業のようなステレオタイプな地方イメージは刺さらない。
  実写ベースで作る。
- **モチーフ**: JUNC = JUNCTION（交差点）由来。交差点の俯瞰カット、ロゴのアニメーション（横断歩道に
  合わせて動かす、無限スクロールなど）を軸に構成する。
- **デザイン**: あえて平面（2D）で統一する。立体表現は今回は使わない — 平面基調の中に急に3Dロゴが
  出ると違和感が出るため。
- **構成の流れ（案）**: 交差点や松山城など愛媛の人が見てわかる場所 → ロゴ導入 → クライマックス
  （経営者が学び集う実写素材）→ 締め。
- **想定視聴者数**: 200〜250人。難しく考えすぎず「かっこいい動画」を作ることを優先する。

## BGM方針

1曲をそのまま使うのではなく、**複数曲の「おいしい部分」を切り出して1本に繋ぐ**アプローチを取る。
冒頭は盛り上がっていく系、クライマックスは映画系など、シーンごとに適した曲の断片を組み合わせる。
`scripts/bgm_stitch.py` はこの作業を自動化するための土台。

## AI活用の考え方

- Claude Code から複数のAI生成モデル（画像・動画・音楽）をAPI経由で呼び出し、アイデア出し〜量産までを
  高速に回す。タイムライン上での手作業編集は最小限にし、生成 → ピック → DaVinci Resolve等で最終調整、
  という流れ。
- 同じプロンプトで複数モデルに同時生成させて比較する（例: 同じプロンプトで動画モデルA/B/Cに4本ずつ
  作らせて一番良いものを選ぶ）。`scripts/generate_media.py` はこの並列生成の土台。
- 各社バラバラにAPIキーを契約すると管理が煩雑になるため、複数プロバイダーを1つのゲートウェイ/APIキー
  で束ねられるサービスの利用も検討する（契約先は未確定 — `.env.example` 参照）。
- API利用は従量課金。実行前に想定コストを確認すること。
